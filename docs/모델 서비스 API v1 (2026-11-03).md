# 모델 서비스 API v1 (2026-11-03)

대상: 백엔드(유우나). 연구실 PC에서 도는 모델 서비스 `src/server.py`(FastAPI)의 호출 방법. 파일별 역할은 저장소 README의 폴더 구조 절에 있고, 이 문서는 그 함수들을 HTTP로 부르는 법만 적는다.
상태: 2026-11-03 로컬 점검 18/18 통과(`src/results/server_check_20261103_1234.md`), 외부 LLM 경로 점검 4건 통과(`src/results/external_check_20261103_1230.md`). 클라우드 서버와의 연결은 2026-11-10 에 끝났다(TK-75).

## 1. 한눈에

| 항목 | 내용 |
|---|---|
| 주소 | 연구실 PC 포트 8010. 터널 연결 전에는 `127.0.0.1:8010`만. 연결 뒤에는 Tailscale IP(또는 터널 호스트명)로 같은 경로 |
| 인증 | 모든 요청에 `X-API-Key` 헤더. 키는 따로 전달한다. `GET /health`만 키 없이 열려 있다(헬스체크용) |
| 형식 | 요청·응답 모두 JSON(UTF-8). 글자 위치(start, end)는 Python 문자열 인덱스. 한글·영문은 JS 인덱스와 같고, 이모지 같은 보조 평면 문자만 다르다 |
| 요청 하나의 호출 순서 | ① 접수 때 `/detect/instant`(동기, 수십 ms) → 1차 카드 ② 배경 작업으로 `/analyze` → 2차 카드·결정·승인 필요 여부·가림 미리보기 ③ 승인 카드에서 이름 토글을 바꾸면 `/mask` ④ 승인되면 `/answer_external`(가림 본문을 Anthropic에 보내고 복원까지 한 번에) ⑤ 사내 처리는 `/answer_local`. 백엔드가 외부 LLM을 직접 부르는 구조로 가면 ④ 대신 `mask.masked`를 보내고 답을 `/restore`에 넣는다 |
| 백엔드 타임아웃 권고 | 연결 5초. 읽기: `/detect/instant` 10초, `/analyze` 180초(45,000자 문서가 약 140초), `/answer_local`·`/answer_external` 240초, 나머지 60초 |
| 입력 상한 | 글 60,000자(`extract.py`의 상한과 같다). 넘으면 422. 더 긴 문서는 백엔드가 나눠서 보낸다. `instruction`은 4,000자, `request_id`는 64자, `doc_name`은 255자까지 |

본문은 `text` 하나로 보내도 되고 `instruction`(직원 요청문) + `body`(PDF에서 뽑은 글자)로 나눠 보내도 된다. 나눠 보내면 서버가 `요청문 + 빈 줄 + 본문`으로 합쳐 검사하고 `body_offset`(본문이 시작하는 글자 번호)을 돌려준다. 구간 위치는 합친 글 기준이므로 본문 하이라이트는 `start - body_offset`. 외부로 나가는 가림 본문도 합친 글이다(요청문도 같이 검사·가림된다). 백엔드는 나눠 보내는 쪽을 권한다.

## 2. 경로

### GET /health — 키 없이
`{"ok": true, "service": "woowang-model-service", "version": "0.1.0"}`

### GET /status
Ollama 상주 모델, 사전 크기, NER 준비 여부, 처리 건수, 버전.
```json
{"ok": true, "uptime_s": 3600, "requests": 34, "errors": 0, "analyze": 10, "ner_ready": true,
 "warm": {"route": 2.1, "llm": 16.8, "embed": 1.7},
 "ollama": {"ok": true, "loaded": [{"name": "qwen3:30b-a3b-instruct-2507-q4_K_M", "size_gb": 19.2, "vram_gb": 6.2}, {"name": "tev1-cpu:latest", "size_gb": 1.3, "vram_gb": 0.0}]},
 "dict": {"companies.txt": 21, "projects.txt": 5}, "llm_busy": false,
 "external": {"key": true, "model": "claude-sonnet-5-5"},
 "versions": {"service": "woowang-model-service", "version": "0.1.0", "code": "a1b2c3d4e5", "dict": "f6a7b8c9d0",
              "llm_model": "qwen3:30b-a3b-instruct-2507-q4_K_M", "prompt_mode": "C", "route_model": "tev1-cpu",
              "route_variant": "v1_en_capability", "ner_model": "atonlee/koelectra-ko-pii-ner", "embed_model": "bge-m3-cpu"}}
```

### POST /detect/instant — 즉시 탐지(규칙·사전·NER), 13~32ms
요청: `{"instruction": "아래 보고서를 영문으로 번역해 주세요.", "body": "…", "request_id": "r_01J…", "doc_name": "분기납품실적.pdf"}`
```json
{"request_id": "r_01J…", "doc_name": "분기납품실적.pdf", "text_chars": 2546, "body_offset": 24,
 "spans": [{"start": 118, "end": 130, "text": "BRK-1120-03A", "label": "doc_no", "sources": ["rule:part_code"], "tier": 1}],
 "sensitive": true, "timing": {"rules_ms": 0.4, "ner_s": 0.018, "total_ms": 19.6}, "warnings": [], "versions": {…}}
```

### POST /analyze — 탐지(30B 포함) ∥ 라우팅 → 결정 → 가림, 1~8초
요청:
```json
{"instruction": "아래 보고서를 영문으로 번역해 주세요.", "body": "…", "request_id": "r_01J…", "doc_name": "분기납품실적.pdf",
 "policy": {"mask_person": false, "mask_company": true}, "use_llm": true}
```
`use_llm: false`면 30B 없이 즉시 경로만 돌리고 `mode`가 `instant_only`가 된다(연구실 PC 부하 시험·간단 모드 재현용). `route_variant`는 기본값 `v1_en_capability`를 그대로 둔다. 경로 판정(tev1)은 합친 글의 앞 6,000자만 본다(`route.truncated`).

응답 필드:

| 필드 | 내용 |
|---|---|
| `request_id`, `doc_name`, `text_chars`, `body_offset` | 요청 그대로 되돌려 줌 + 합친 글 길이 + 본문 시작 위치 |
| `mode` | `full`(30B·tev1 모두 동작) / `degraded`(둘 중 하나가 실패, `warnings`에 사유) / `instant_only`(`use_llm:false`) |
| `spans[]` | 최종 구간. `{start, end, text, label, sources[], tier, masked, placeholder}`. 위치는 합친 글의 문자 인덱스이고 `end`는 포함하지 않는다(`text[start:end]`). 구간끼리 겹치지 않는다(병합 뒤). label은 company·project·doc_no·price·person·contact·biz_no, 그리고 30B가 이 일곱 밖으로 분류한 other. tier는 1(항상 가림)·2(이름, 정책)·3(other, 가리지 않음). sources는 `rule:…`, `dict:…`, `ner:…`, `llm`, `propagate`. `masked`는 요청의 policy로 가려졌는지, `placeholder`는 그때의 자리표(안 가려졌으면 null) |
| `rule_spans[]`, `llm_spans[]` | 즉시 경로만의 구간, 30B만의 구간(대시보드 "탐지기별 기여"용) |
| `sensitive` | 구간이 하나라도 있으면 true |
| `route` | `{choice: local/external/block, probabilities: {local, external, block}, confidence, seconds, input_tokens, state_chars, truncated}`. tev1 실패면 null이고 `route_error`에 사유. 합친 글이 6,000자를 넘으면 앞 6,000자만 tev1에 보내고 `truncated: true`(11-05. 그 전에는 tev1 컨텍스트 8,192토큰 때문에 약 1만 2천 자부터 항상 실패해 축소 모드로 빠졌다) |
| `decision` | `{action: local/external/block, needs_approval, reasons[], warnings[]}`. `needs_approval`은 external이면서 구간이 있을 때만 true |
| `mask` | `{masked, mapping: {"[[ORG_1]]": "(주)한빛에어로", …}, entries: [{start, end, text, label, placeholder}], unmasked: [{start, end, text, label, reason}], policy}`. 요청의 policy로 가린 미리보기. 승인 카드에서 토글이 바뀌면 `/mask`로 다시 만든다 |
| `external_instruction` | 외부 요청 앞에 붙이는 안내문 한 줄("[[ORG_1]] 같은 표기는 자리표…"). 외부 호출 본문 = 이 문장 + 빈 줄 + `mask.masked` |
| `warnings[]` | 탐지·결정·라우팅 경고를 합친 것. 지시 삽입 감지, 30B 실패, 출력 상한 끊김, tev1 실패 폴백 |
| `dropped[]` | 30B가 원문에 없는 글자를 돌려줘 버린 항목(품질 추적용) |
| `timing` | `rules_ms, ner_s, injection_blanked, chunks, llm_total_s, llm_load_s, llm_prompt_eval_s, llm_eval_s, llm_prompt_tokens, llm_eval_tokens, route_s, total_s` |
| `versions` | `/status`와 같은 버전 묶음. 로그에 같이 저장하면 어떤 코드·사전으로 낸 결과인지 재현 가능 |

### POST /mask — 가림 다시 만들기, 0ms
요청: `{"text": "<합친 글>", "spans": [/analyze 응답의 spans 그대로], "policy": {"mask_person": true}}`
응답: `/analyze`의 `mask`와 같은 형식. 구간 위치가 글 밖이면 422.

### POST /restore — 외부 답변 복원, 0ms
요청: `{"answer": "<외부 LLM 답변>", "mapping": {"[[ORG_1]]": "(주)한빛에어로", …}}`
응답: `{"restored": "…", "unresolved": ["[[ORG_9]]"]}`. 자리표의 변형(`[[ ORG_1 ]]`, `[ORG_1]`, `[[org-1]]`)도 되돌리고, 대응표에 없는 자리표는 추측해 채우지 않고 `unresolved`에 남긴다.

### POST /answer_local — 사내 처리(4.1), 30B가 원문으로 답변
요청: `{"instruction": "…", "body": "…", "request_id": "r_01J…", "max_tokens": 1024}`
응답: `{"request_id", "answer", "model", "seconds", "prompt_tokens", "eval_tokens", "done_reason", "truncated", "warnings"}`. 6,000자를 넘는 글은 문맥 4,096토큰에 잘릴 수 있다는 경고가 붙는다. Ollama 호출 실패는 503.

### POST /answer_external — 외부 전송(4.2), 가림 본문을 Anthropic API로 보내고 답변을 복원, 3~10초
두 형식 중 하나로 보낸다.
- (a) `/analyze`가 돌려준 가림 본문과 대응표 그대로: `{"masked": "…", "mapping": {"[[ORG_1]]": "(주)한빛에어로", …}, "request_id": "r_01J…"}`
- (b) 서버가 가림부터: `{"text": "<합친 글>", "spans": [/analyze의 spans], "policy": {"mask_person": false}, "request_id": "r_01J…"}`

선택 항목: `model`(기본 claude-sonnet-5-5), `effort`(low/medium/high/xhigh/max, 기본 medium), `max_tokens`(기본 16000), `fallback`(기본 true: 외부 모델이 거부하면 Anthropic의 대체 모델이 같은 호출 안에서 이어받는다. 대체 모델도 가림 본문만 받는다).
자리표 유지 안내문은 서버가 system으로 붙이므로 따로 넣지 않는다. 보내기 직전에 원문 값이 가림 본문에 남아 있는지 검사해 남아 있으면 보내지 않고 409. 키가 연구실 PC에 없으면 503.
```json
{"request_id": "r_01J…", "answer": "<자리표가 그대로인 외부 답변>", "restored": "<자리표를 원문으로 되돌린 답변>", "unresolved": [],
 "placeholders": {"sent": 11, "kept": 11}, "stop_reason": "end_turn", "truncated": false, "refusal": null,
 "model": "claude-sonnet-5-5", "served_by": "claude-sonnet-5-5", "fallback_ran": false, "effort": "medium",
 "usage": {"input_tokens": 633, "output_tokens": 661, "cache_read": 0, "cache_write": 0}, "cost_usd": 0.00788, "seconds": 4.78,
 "anthropic_request_id": "req_…", "notes": []}
```
(b) 형식이면 `masked`, `mapping`, `entries`, `unmasked`, `policy`도 함께 돌아온다. 화면에는 `restored`를, 로그에는 `answer`와 `restored`를 둘 다 둔다. `placeholders.kept`는 보낸 자리표 종류 중 답변에 남은 수이고 요약 작업이면 전부 나오지 않아도 정상이다. `unresolved`는 대응표에 없는 자리표(0이어야 함). 거부면 `stop_reason: "refusal"`, `answer`와 `restored`는 빈 문자열, `refusal: {category, explanation}`.

### POST /embed — 유사 기록 조회(⑨)용 벡터
요청: `{"texts": ["…", "…"]}`(1~64건) → `{"model": "bge-m3-cpu", "dim": 1024, "embeddings": [[…], […]], "seconds": 0.3}`. pgvector `vector(1024)` 열에 그대로 넣는다.

### POST /dict/reload — 사전 갱신·재적재(⑧ 학습 배치)
요청: `{"companies": ["츄러스 공업|츄러스공업", "우왕 전자"], "projects": ["스위트라인 생산설비 개선사업"]}`
목록을 준 파일은 그 내용으로 통째 교체(이전 파일은 `.bak`), 한 항목에 `|`로 별칭을 나란히 적는다. `{}`로 보내면 파일만 다시 읽는다.
응답: `{"ok": true, "written": ["companies.txt", "projects.txt"], "terms": {"companies.txt": 23, "projects.txt": 6}, "dict_hash": "…"}`

## 3. 실패했을 때

| 상황 | 동작 |
|---|---|
| 30B 호출 실패·시간 초과(90초) | 200. `mode: degraded`, `spans`는 즉시 경로 결과만, `warnings`에 "정밀 검사(30B) 호출 실패" |
| tev1 호출 실패 | 200. `route: null`, `route_error`, `decision.action: local`(폴백, reasons "라우팅 불가(폴백)"), `mode: degraded` |
| Ollama 전체 다운 | 위 둘이 함께. 즉시 탐지·가림·복원은 그대로 동작 |
| 서비스 자체 다운(연구실 PC 꺼짐) | 백엔드가 간단 모드로: 즉시 경로 패키지(규칙·사전·NER, CPU만)를 서버에 설치해 두면 같은 결과를 낸다. 패키지는 따로 전달 |
| 외부 LLM 키 없음·틀림 | `/answer_external` 503 |
| 전송 직전 유출 검사 | `/answer_external` 409. 가림 본문에 원문 값이 남아 있어 보내지 않았다는 뜻이고, 가림 단계의 결함 신호이니 보안팀 로그에 남긴다 |
| 외부 LLM 거부(refusal) | 200. `answer`·`restored` 빈 문자열, `refusal.category`. `fallback`이 켜져 있으면 대체 모델이 이어받고 `served_by`·`fallback_ran`에 표시 |
| 외부 LLM 한도·장애 | 429(호출 한도), 502(Anthropic 5xx·연결 실패). SDK가 429·5xx는 2회 자동 재시도한 뒤의 결과 |
| 401 | 키 없음·틀림 |
| 422 | 빈 글, `text`와 `body` 동시, 60,000자 초과, 구간 위치가 글 밖, 모르는 `route_variant`, `/answer_external`에 두 형식을 섞거나 한 쌍을 덜 보냄 |
| 503 | `/answer_local`, `/embed`의 Ollama 호출 실패 |
| 500 | `{"error": "<예외 이름>", "detail": "<300자>"}` |

## 5. 운영

```powershell
# 연구실 PC, 작업 폴더(woowang)에서. 키는 쉼표로 여러 개(백엔드용·대시보드용 따로)
$env:MODEL_API_KEYS = "<키1>,<키2>"
.venv\Scripts\python.exe src\server.py --host 127.0.0.1 --port 8010      # 터널 연결 뒤에는 --host 0.0.0.0 (Tailscale ACL로 백엔드만 허용)

# 점검(서버를 직접 띄우고 시연 6건·TEST-01을 HTTP로 통과시킨다)
.venv\Scripts\python.exe src\tools\server_check.py
```

- `MODEL_API_KEYS`가 비어 있으면 임시 키를 만들어 stderr에 한 번 찍는다. 키 없이 열리는 경우는 없다.
- `MODEL_WARM_OLLAMA=0`이면 시작 뒤 예열을 건너뛴다(기본은 예열).
- Ollama는 `OLLAMA_MAX_LOADED_MODELS=3`, `OLLAMA_KEEP_ALIVE=-1`로 세 모델을 상주시킨다. 없으면 30B가 매번 14~17초 재로드된다.
- 서버 로그에는 요청 id·글자 수·구간 수·결정·시간만 남고 원문·대응표·문서명은 남지 않는다. 원문은 응답에만 있다.
- 외부 LLM 키는 연구실 PC의 사용자 환경변수 `ANTHROPIC_API_KEY`에만 있다(코드·git·Notion·채팅에 적지 않는다). 기본 모델은 `EXTERNAL_MODEL`로 바꾼다. 생각 깊이는 요청의 `effort`로 준다(서비스 기본은 medium 고정이고, `EXTERNAL_EFFORT`는 `external_check.py` 같은 직접 호출에만 적용된다). 백엔드가 외부 LLM을 직접 부르는 구조로 바뀌면 키를 GCP 비밀 저장소로 옮기고 `/answer_external`은 끈다.
- 아직 없는 것: 유사 사례를 30B에 넘기는 `examples` 입력(RAG, pgvector가 서면 추가), OCR(이미지 PDF). 자동 재시작은 `ops/`의 작업 스케줄러 등록으로 한다(`ops/README.md`).

## 6. ⑥ 로그 DB 저장 대응(제안)

| DB | 응답 필드 |
|---|---|
| requests.doc_name, requests.prompt, requests.doc_text | 요청 때 백엔드가 가진 값(`doc_name`은 응답에도 되돌아온다) |
| requests.route, requests.decision | `route`, `decision` 그대로(jsonb) |
| requests.analysis | `mode`, `timing`, `warnings`, `dropped`, `versions`, `body_offset`, `text_chars` |
| requests.mask | `mask.mapping`, `mask.entries`, `mask.unmasked`, `mask.policy` |
| requests.latency_ms | `timing.total_s × 1000` |
| spans | `spans[]`의 `start, end, text, label, sources, tier`. `masked`는 `mask.entries`에 같은 위치가 있으면 true, `placeholder`도 거기서 |
| answers(kind=local) | `/answer_local`의 `answer, model, prompt_tokens, eval_tokens, seconds` |
| answers(kind=external) | `/answer_external`의 `answer`(자리표 그대로), `restored`, `served_by`, `usage.input_tokens`·`output_tokens`, `cost_usd`, `stop_reason`, `seconds` |
| events | `warnings`의 지시 삽입 감지, `mode: degraded`, 차단 |

대시보드 집계는 `spans.label/tier`, `decision.action`, `warnings` 개수, `timing`만 읽으면 되고 원문 열을 볼 필요가 없다.
